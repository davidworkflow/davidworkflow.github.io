# David — Software Engineer Portfolio (React)

React 18 + Vite single-page portfolio.

## Run
```
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs to dist/
```

## Edit content
Everything lives in `src/data.js` (profile, stats, experience, projects, skills).

The companies in the Experience section are **fictional** (Lumenstack Technologies, Brightforge Systems,
Cobaltgrid Software, Pinecrest Digital Labs). Stats, bullets and projects are placeholders too — replace
them with facts you can back up before sharing.

## Deploy
Upload `dist/` to Netlify/Vercel, or use GitHub Pages (`base: './'` is already set).
